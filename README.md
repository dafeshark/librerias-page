# librerias-page

Librerias para la pagina de satelites y basura espacial.

- three: motor 3D
- satellite.js: posiciones orbitales (SGP4)
- @designcodeio/threeui: efectos y shaders
- react, react-dom, vite: base del proyecto

## Uso
npm install
cp .env.example .env   # credenciales de Space-Track (nunca se suben)
npm run dev
